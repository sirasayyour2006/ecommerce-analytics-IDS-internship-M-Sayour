# KPI Definitions

## Project Overview

This document provides a brief explanation of the KPIs and visuals used in the Power BI dashboard for the E-commerce Analytics Project.

The dashboard was built using the SQL star schema created in Week 2.

Main tables used:

- `fact_orders`
- `dim_customers`
- `dim_products`
- `dim_date`

The Power BI report contains four dashboard pages:

1. Sales Overview
2. Product Performance
3. Regional Performance
4. Delivery Performance

---

# 1. Sales Overview Dashboard

The Sales Overview page summarizes the main sales performance of the e-commerce business.

## Total Revenue

### Definition

Total Revenue represents the total amount generated from delivered orders.

### DAX Formula

```DAX
Total Revenue = SUM(fact_orders[item_revenue])
```

### Purpose

This KPI helps management understand the overall revenue generated by the business.

---

## Orders

### Definition

Orders represents the total number of unique orders.

Because the fact table is at order-item level, the same order can appear more than once. Therefore, `DISTINCTCOUNT` is used to avoid double-counting orders.

### DAX Formula

```DAX
Orders = DISTINCTCOUNT(fact_orders[order_id])
```

### Purpose

This KPI shows the number of completed customer orders.

---

## Average Order Value (AOV)

### Definition

Average Order Value measures the average revenue generated per order.

### DAX Formula

```DAX
AOV = DIVIDE([Total Revenue], [Orders])
```

### Purpose

This KPI helps evaluate how much revenue each order generates on average.

---

## Monthly Revenue Trend

### Definition

Monthly Revenue Trend shows how total revenue changes over time by month.

### Fields Used

```text
X-axis: dim_date[year_month]
Y-axis: Total Revenue
```

### Purpose

This visual helps identify monthly revenue patterns, growth trends, and seasonality.

# 4. Delivery Performance Dashboard

The Delivery Performance page analyzes delivery performance by comparing delayed orders with on-time orders.

## Delivery Status

### Definition

Delivery Status classifies each order as either delayed or on time.

### DAX Formula

If `is_delayed` is stored as True/False:

```DAX
Delivery Status =
IF(fact_orders[is_delayed] = TRUE(), "Delayed", "On Time")
```

If `is_delayed` is stored as 0 and 1:

```DAX
Delivery Status =
IF(fact_orders[is_delayed] = 1, "Delayed", "On Time")
```

### Purpose

This field is used to compare delayed orders with on-time orders in the Delivery Performance dashboard.

---

## Delayed Orders

### Definition

Delayed Orders represents the number of unique orders delivered after the estimated delivery date.

### DAX Formula

If `is_delayed` is stored as True/False:

```DAX
Delayed Orders =
CALCULATE(
    DISTINCTCOUNT(fact_orders[order_id]),
    fact_orders[is_delayed] = TRUE()
)
```

If `is_delayed` is stored as 0 and 1:

```DAX
Delayed Orders =
CALCULATE(
    DISTINCTCOUNT(fact_orders[order_id]),
    fact_orders[is_delayed] = 1
)
```

### Purpose

This KPI helps measure late delivery performance.

---

## On Time Orders

### Definition

On Time Orders represents the number of unique orders delivered on or before the estimated delivery date.

### DAX Formula

If `is_delayed` is stored as True/False:

```DAX
On Time Orders =
CALCULATE(
    DISTINCTCOUNT(fact_orders[order_id]),
    fact_orders[is_delayed] = FALSE()
)
```

If `is_delayed` is stored as 0 and 1:

```DAX
On Time Orders =
CALCULATE(
    DISTINCTCOUNT(fact_orders[order_id]),
    fact_orders[is_delayed] = 0
)
```

### Purpose

This KPI helps measure successful delivery performance.

---

## Delayed Percentage

### Definition

Delayed Percentage measures the percentage of orders that were delivered late.

### DAX Formula

```DAX
Delayed % = DIVIDE([Delayed Orders], [Orders])
```

### Purpose

This KPI shows the proportion of delayed orders out of total orders.

---

## On Time Percentage

### Definition

On Time Percentage measures the percentage of orders delivered on time.

### DAX Formula

```DAX
On Time % = DIVIDE([On Time Orders], [Orders])
```

### Purpose

This KPI shows the proportion of orders delivered on time.

---

## Delayed vs On-Time Percentage

### Definition

Delayed vs On-Time Percentage compares delayed orders with on-time orders.

### Visual Used

```text
Visual: Donut Chart
Legend: Delivery Status
Values: Orders
```

### Purpose

This visual provides a clear overview of delivery performance and shows whether most orders were delivered on time or delayed.
